Here's the exact sequence of commands to run everything:

Step 1 — Activate virtual environment
bashcd DATATHON
source line/bin/activate        # Linux/Mac
# OR
line\Scripts\activate           # Windows

Step 2 — Install dependencies
pip install -r requirements.txt

Step 3 — Start Docker (PostgreSQL + Redis)
docker compose up -d
Verify both containers are running:
docker ps
You should see datathon_postgres and datathon_redis both with status healthy.

Step 4 — Verify DB connection
docker exec -it datathon_postgres psql -U datathon_user -d datathon_db -c "\dt"
If it says No relations found — that's fine, tables get created in the next step.

Step 5 — Seed the database
python seed_mock_data.py

Step 6 — Verify data in DB

"
Or check row counts directly:
docker exec -it datathon_postgres psql -U datathon_user -d datathon_db -c "
SELECT 'products' AS tbl, COUNT(*) FROM products

Step 7 — Run the live scraper (one shot, no scheduler)
To test scraping works before committing to the scheduler:
python -c "
from pipeline.db.database import engine
from pipeline.db.models import ensure_schema
from pipeline.scheduler import run_competitor_pipeline, run_seller_pipeline
ensure_schema(engine)
run_seller_pipeline()
run_competitor_pipeline()
"
Watch the output — you should see prices and ratings coming in live from Amazon.

Step 8 — Generate embeddings
python -c "
from pipeline.competitors.embedding_service import embed_all_missing
embed_all_missing()
"

⚠️ Requires OPENAI_API_KEY in .env. Skip this if you don't have one yet — everything else still works.


Step 9 — Run competitor detection
python -c "
from pipeline.competitors.similarity_search import detect_all_competitors
detect_all_competitors()
"

Only works after Step 8 (needs embeddings). Check results:

docker exec -it datathon_postgres psql -U datathon_user -d datathon_db -c "SELECT * FROM competitors;"

Step 10 — Start the full scheduler
Once everything above is verified, start the recurring pipeline:
python -m pipeline.scheduler
This will:

Sync schema
Run the full pipeline immediately
Then repeat every 3 hours automatically

Press Ctrl+C to stop.
